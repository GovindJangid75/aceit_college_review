# Arya College Review Collector

A simple practice mini-project — a review collector web page for **Arya College of Engineering & IT (ACEIT)**, Jaipur.

---

## Features

- Dark / Light mode toggle
- Live clock in the header
- Star rating system (1–5 stars)
- Submit and display student reviews
- Average rating calculation
- Query/contact form (stores in `localStorage`)
- College info: courses, placements, hostels, achievements
- Pros & Cons section
- Responsive layout for mobile and desktop

---

## Project Structure

```
├── index.html    # Page structure and content
├── style.css     # Styling and dark/light theme
└── script.js     # Theme toggle, clock, reviews, query form
```

---

## How to Run

No setup needed. Just open `index.html` in a browser.

> **Note:** Review submission and loading requires a backend API at `/api/reviews`. Without it, those features won't work — but the rest of the page works fine.
